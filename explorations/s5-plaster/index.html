Stock
Pale lime plaster #D2CDBD, with the warmer rust render exposed where the skin has fallen away.
Plane
Two materials level with each other. The render is not behind the plaster; there is no depth between them and nothing casts a shadow.
Break
Hard, and friable at fibre scale. Plaster comes away in plates, so the edge is broken rather than blurred.
Stain
Rust bleeds outward from the exposed regions into the lime, so the two contaminate each other across a boundary that is otherwise sharp.
Pigment
#8F4F30 at 3.97:1, so it carries areas and large type but never small text. The lip on it reaches 4.88:1.
Type
Young Serif 400 and Courier Prime 400/700, both SIL OFL 1.1. Licence files are not yet vendored alongside them.
Measured
Ink on stock 9.46:1 · quiet 5.18:1 · lip on pigment 4.88:1
